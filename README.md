# PortfolioHub 资产罗盘 📈

> 专为个人打造的跨平台多账户股票与基金实时监控、盈亏核算与异动预警系统。  
> **纯自动化同步驱动**：聚合 **天天基金**、**雪球基金**、**东方财富**（A股/ETF/可转债），无需任何手动录入，配置凭证即可全自动拉取持仓、份额与成本，提供毫秒级股票行情与盘中基金实时估算净值。

---

## ✨ 核心特性

1. **三合一多账户全自动同步（零手动录入）**：
   - **东方财富**：支持 Web 交易凭证同步，自动拉取 A股、场内 ETF、可转债实盘持仓与真实买入成本。
   - **天天基金**：支持凭证自动拉取场外公募基金持有份额与成本，盘中计算预估净值，收盘同步官方公布权威净值。
   - **雪球基金**：支持 `xq_a_token` 自动拉取自选、实盘持仓组合与蛋卷基金。
2. **多源秒级行情抓取**：
   - 股票/ETF：无频率限制腾讯/新浪高并发实时行情。
   - 基金：盘中（9:30-15:00）动态计算实时预估涨跌幅，收盘后自动同步权威净值。
3. **盘中异动与定时战报**：
   - 支持设置日涨跌幅阈值（如±3%）、累计止盈线、止损线。
   - 工作日 **09:25 开盘提醒**、**15:05 收盘战报**、**21:45 基金净值更新报告**。
   - 支持 **微信 PushPlus 推送**（一对一微信服务号/群组通知）。
4. **轻量高效设计**：
   - 移除笨重的 Excel 解析库及手工账本冗余，纯原生 HTTP 异步引擎驱动，秒级极速启动。

## 🚀 极简启动方式

双击根目录下的 `start.bat` 即可一键启动后端服务与定时任务，并自动在浏览器中打开：
```
http://127.0.0.1:8000
```

## 🔑 三大平台凭据获取指南

在系统右上角点击 **【账户同步】**，即可配置对应平台的凭证：

### 1. 雪球基金 (Cookie 同步)
1. 在电脑浏览器打开 [雪球网](https://xueqiu.com) 并登录账号。
2. 按 `F12` 打开开发者工具，点击 **Application (应用程序)** -> **Cookies** -> `https://xueqiu.com`。
3. 找到名为 `xq_a_token` 的 Cookie 项，复制其值并保存至系统雪球配置中。

### 2. 天天基金 (Token / Cookie 同步)
1. 手机端通过抓包工具，或浏览器打开天天基金交易 H5 页面 (`tradeh5.1234567.com.cn`) 登录。
2. 复制请求头中的 `Cookie` 字符串保存至系统天天基金配置中。

### 3. 东方财富 (Web 交易实盘同步)
1. 在浏览器打开东方财富网上交易端 (`jywg.18.cn`) 并登录。
2. 按 `F12` 打开开发者工具，在网络请求中复制当前域名的 `Cookie` 粘贴保存。
3. 点击【同步】即可自动获取全部股票、场内 ETF、可转债实盘持仓数及买入成本。
