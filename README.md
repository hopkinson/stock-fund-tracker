# PortfolioHub 资产看板 📈

> 个人多账户股票与基金看板。自动同步 **东方财富**、**天天基金**、**雪球** 持仓与成本，实时查看今日盈亏与总收益，支持微信涨跌提醒。

---

## ✨ 主要功能

1. **多平台自动同步**：
   - **东方财富**：自动同步 A股、ETF 持仓数量与买入成本。
   - **天天基金**：自动同步场外基金持有份额与成本，实时计算盘中预估净值。
   - **雪球**：自动同步雪球持仓与自选基金。
2. **实时价格与盈亏**：
   - 股票与 ETF 实时价格刷新。
   - 基金交易时间内实时估算净值，收盘后自动同步公布净值。
3. **微信消息提醒**：
   - 支持设置涨跌幅提醒与止盈止损线。
   - 交易日 **09:25 开盘提醒**、**15:05 收盘日报**、**21:45 基金净值更新** 发送到微信。
4. **AI 智能分析**：
   - 接入 DeepSeek 等大模型，一键分析持仓分布、板块集中度与操作建议。

## 🚀 启动方式

双击运行根目录下的 `start.bat` 即可启动服务，并自动在浏览器中打开：
```
http://127.0.0.1:8000
```

## 🔑 账号绑定步骤

在看板右上角点击 **【同步持仓】**，即可绑定平台账号：

### 1. 雪球
1. 打开 [雪球网](https://xueqiu.com) 登录账号。
2. 按 `F12` 打开控制台，在【同步持仓】弹窗中点击【复制提取代码】，在控制台粘贴回车。
3. 将复制的内容粘贴到输入框中保存。

### 2. 天天基金
1. 浏览器打开天天基金交易页面 (`tradeh5.1234567.com.cn`) 登录。
2. 在【同步持仓】弹窗中点击【复制提取代码】，在控制台粘贴回车复制 Cookie。
3. 粘贴到输入框中保存。

### 3. 东方财富
1. 浏览器登录东方财富网上交易端 (`jywg.18.cn`)。
2. 按 `F12` 打开开发者工具，切到【网络 (Network)】标签。
3. 点击页面左侧【资金持仓】，在网络请求列表中找到任意请求，复制请求标头中的 Cookie 粘贴保存即可。
